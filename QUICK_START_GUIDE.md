## ⚡ 5-MINUTE SETUP

### Step 1: Create Project Folder
```bash
mkdir StudentGradeManagementSystem
cd StudentGradeManagementSystem
```

### Step 2: Create Folder Structure
```bash
mkdir src
mkdir src/models
mkdir src/services
mkdir src/dao
mkdir src/ui
mkdir src/utils
mkdir data
mkdir reports
```

### Step 3: Copy Java Files
Copy the code from `Java_Source_Code.md` into respective directories:
- `Student.java`, `Grade.java`, etc. → `src/models/`
- `GradeService.java`, etc. → `src/services/`
- `Application.java` → `src/`
- `ValidationUtil.java`, etc. → `src/utils/`

### Step 4: Compile
```bash
cd src
javac *.java
javac models/*.java
javac services/*.java
javac utils/*.java
```

### Step 5: Run
```bash
java Application
```
